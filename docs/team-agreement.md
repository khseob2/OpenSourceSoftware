## 2. 소통
- 채널: 디스코드 서버 'RPS'
- 정기 회의: 매주 금요일 13:00 ~ 13:30, 온라인. 추가 회의가 필요할 시 디스코드로 진행
- 응답: 채팅 4시간, 풀 리퀘스트 리뷰 48시간
## 3. 작업 규칙
- 작업 전 이슈 등록, 하루 작업 끝에 Push (내 PC에만 두지 않기)
- 한 줄, 한글로| 무엇을 했는지 보이게 작성
- 이슈 번호 포함| 끝에(#번호) 붙이기
- 의미 있는 메세지만 보내기| 수정, 최종, asdf 같은 메세지 금지
- 잘못 썼으면 어멘드로 고치기 | Push 전에만 마지막 커밋 정정
## 4. 의사결정
- 회의에서 다수결, 동률이면 개발 리드 결정. 결과는 회의록에 기록
